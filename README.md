# Measurement-Equipment（量具全生命周期管理平台 · MIM）

做一个量仪从申购、采购、登记、使用、定期校验、维修、报废的管理平台，让公司每个人用的量仪都得到合适管理，防止非法、未经校验的量仪用于生产，影响产品品质。

核心命题：在生产的每一刻，都能证明手上这把量具是合格的；**不能证明，就不许用**。
