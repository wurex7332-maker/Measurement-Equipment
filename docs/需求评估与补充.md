## 三、建议确认的矛盾点（逐条比对发现）

| # | 问题 | 依据 |
|---|---|---|
| 3 | **编号正则与 3D 类别码冲突**：正则首位限字母，但 3D10001 首位是数字，按该正则会被拒绝——与文档兼容 3D 自相矛盾。建议首位改 [A-Z0-9] | PRD §10.3 规则 6 |
| 4 | **内/外校的 S0/S1 分期完全反转**：FR-33/36（外校送检、外校证书）标 S0，FR-34（内校记录标准器/环境/校验员）标 S1；但 §13.1 写 S0 做内校登记、S1 做外校与标准器，DEV T4 验证又含外校证书。S0 到底交付哪些需定死 | PRD §7.6、§13.1、DEV T4 |
| 5 | **G-04 与 S0 门槛口径冲突**：G-04 要求 S0 结束覆盖率 ≥25%（约 400 台），但 S0 门槛和 T2b 只要求试点 ≥100 台（=6.7%）。差了 4 倍 | PRD §2.4、§13.1、DEV T2b |
| 6 | **两个覆盖率指标目标打架**：G-04 赋码覆盖率 S0 结束 25%，G-10 建档覆盖率首月 80%。时间接近、口径相近，看板上容易读混 | PRD §2.4 |
| 7 | **QPS 算不上**：§5.5 写 500 次登记/30 分钟 → 5–8 QPS 均值，实际 500/1800≈0.28 QPS。数字口径需澄清或更正 | PRD §5.5 |
| 8 | **G-09 样本量**：T2b 验证用实测 10 台测 P50，S0 门槛是 100 台 P50≤60s，10 台样本不足以证明 100 台达标 | DEV T2b、PRD §13.1 |

> 更新（2026-11-19）：上述 8 项矛盾已逐条收敛定稿，见 `docs/需求定型-矛盾收敛结论.md`；其中 #4 已依据 PRD v1.2 §7.6 FR 级版本标签定死 A 方案（S0=外校送检/证书/判定/登记/到期拦截/合格后恢复，S1=内校详细/免校/标准器/替代量具），不再待拍板。
